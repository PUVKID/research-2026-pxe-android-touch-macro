설치
2차의 NEX APK를 휴대폰으로 옮겨 내 파일 앱에서 설치하세요.
1차와 같은 앱 ID 및 개인 키를 사용하므로 1차 위에 업데이트 설치할 수 있습니다.
앱의 이름은 NEX로 표시됩니다. 기존 매크로 저장 데이터는 유지됩니다.
처음 설치하면 앱에서 접근성 설정을 열고 NEX 서비스를 켜 주세요.
Android 13 이상에서 접근성이 막히면 앱 정보의 '제한된 설정 허용'을 확인합니다.
Android 13 이상에서 알림을 허용하면 알림에서도 정지/컨트롤 닫기를 사용할 수 있습니다.

가장 중요한 기능: 원하는 글자 인식 → 그 위치 터치
1. NEX 첫 화면의 '글자' 탭에 찾을 문구를 입력합니다.
2. 인식 방식을 자동 / 화면 정보 / OCR 중 선택합니다.
   자동: 일반 버튼과 화면 글자를 먼저 읽고, 없으면 한글 OCR로 찾습니다.
   OCR: 게임, 이미지, 캔버스 등의 글자를 화면 캡처로 인식합니다.
3. 포함 / 완전 일치 / 정규식 비교를 선택합니다.
4. 글자가 없으면 뒤로가기 후 최대 3회 다시 확인하도록 선택할 수 있습니다.
5. '인식 미리보기'는 초록 테두리로 위치만 보여줍니다. 터치하지 않습니다.
6. '글자 모드 실행'은 3초 뒤 검색하여 터치합니다.
7. '이 글자 동작을 매크로에 추가'하면 다른 터치나 스와이프 사이에 넣을 수 있습니다.

다른 앱 위에서 사용하는 권장 순서
1. 아래 '화면 위 컨트롤'을 누릅니다.
2. 자동화할 앱으로 직접 이동합니다.
3. 컨트롤의 '글자'를 눌러 문구를 입력하고 인식/터치/미리보기를 실행합니다.
4. 일반 매크로는 '시작'으로 실행하고 '일시정지/계속/정지'로 제어합니다.
5. 상태 글자를 끌어 컨트롤을 이동하고 '접기'로 작은 버튼으로 줄입니다.
6. 작은 버튼은 눌러 펼치고, 길게 눌러 매크로를 정지할 수 있습니다.
7. 타이머는 경과 시간과 설정한 최대 실행 시간의 남은 시간을 표시합니다.
8. 실행 중 컨트롤과 실제 제스처가 겹칠 때만 컨트롤을 잠시 숨깁니다.
   OCR 캡처 중에는 컨트롤과 번호 점을 잠시 숨겨 인식에 섞이지 않게 합니다.
9. 편집 화면을 열면 실행 중 매크로는 일시정지합니다.
10. 알림에서도 정지하거나 컨트롤을 닫을 수 있습니다.

곡선·멀티터치 녹화
1. 원하는 앱에서 화면 위 컨트롤의 '녹화'를 누릅니다.
2. 탭, 길게 누르기, 곡선 이동, 두 손가락 확대/축소 등을 직접 그립니다.
3. 손을 떼면 그 제스처를 원래 앱에 재생한 뒤 다음 동작을 녹화합니다.
   녹화 입력은 먼저 캡처하며 손을 뗀 후 전달됩니다. 실시간 입력 감시는 아닙니다.
4. '녹화 끝내기'를 누르면 현재 매크로에 보관합니다.
5. 제스처 사이에서 기다린 시간도 이전 동작의 완료 후 대기로 기록합니다.
6. 한 동작만 녹화하거나 기존 동작을 교체하는 기능도 제공합니다.
7. 동시 경로는 최대 20개, 한 제스처는 최대 59초, 경로당 점은 최대 512개입니다.
   경로는 손가락별 시작 시각과 지속 시간으로 재생하며 경로 내부 이동 속도는 균일하게 재구성됩니다.
8. 취소해도 이미 완료한 녹화 동작은 현재 작업에 남습니다. 불필요한 동작은 삭제하세요.

화면 위에서 편집
- 번호 점을 끌어 터치 위치를 바꿉니다. 녹화된 제스처는 전체 경로를 이동합니다.
- '동작 목록'에서 위/아래, 복제, 사용 여부, 삭제, 해당 번호부터 실행, 다시 녹화를 선택합니다.
- '동작 추가'에서 좌표 캡처, 한 동작 녹화, 글자, 뒤로, 대기, 홈, 최근 앱을 추가할 수 있습니다.
- 상세 검색 영역·보정·조건 분기는 앱의 '동작' 탭에서 편집하세요.
- '저장'은 현재 매크로를 이름으로 보관합니다.
- 번호 점은 최대 40개까지만 표시하며 동작 목록은 최대 500개입니다.

글자 동작의 고급 옵션
- 같은 글자 중 몇 번째인지 선택: 위→아래, 같은 높이에서는 왼쪽→오른쪽
- 공백·줄바꿈 및 영문 대소문자 무시
- 검색 영역: 화면 전체의 왼쪽/위/오른쪽/아래 %
- 터치 X/Y 보정: 화면 비율 -50~50%
- 각 화면 검색 시간, 재검색 횟수와 대기 시간
- 없으면 정지 / 건너뛰기 / 뒤로가서 재검색 / 같은 화면 재확인 / 위로 스크롤 후 재검색
- 최대 횟수 후에도 못 찾으면 중단
- 캡처 오류나 OCR 엔진 오류는 '글자 없음'으로 처리하지 않고 중단

동작 목록
좌표 터치, 두 번 터치, 길게 누르기, 스와이프, 곡선 스와이프,
핀치 축소/확대, 동시 다중 터치, 녹화 제스처,
대기, 글자 찾아 터치, 글자 대기, 글자 조건 분기, 글자 인식 확인,
뒤로가기, 홈, 최근 앱, 알림 패널, 문자 입력, 앱 실행, 번호 이동, 정지.

실행 설정과 모양
- 동작마다 지속 시간, 완료 후 대기, 반복 횟수, 시간 무작위 범위
- 전체 반복(0은 무한), 반복 사이 대기, 시작 전 대기, 시작할 번호, 최대 실행 시간
- 기기 설정 따르기 / 라이트 / 다크
- 컨트롤 크기 75~140%, 불투명도 40~100%, 번호 점 표시 여부
- 실행 중 화면 켜짐 유지 선택
- 이름별 저장, JSON 내보내기/불러오기, 실행 기록 TXT 저장
- 동작 번호를 재정렬하거나 삭제한 뒤 조건 분기/번호 이동 설정을 다시 확인하세요.

주의할 동작 범위
OCR 인식은 폰트·화질·배치에 따라 달라집니다. 먼저 인식 미리보기로 확인하세요.
보안 화면은 캡처가 막힐 수 있습니다. 그 앱이 글자 정보를 제공하면 화면 정보 모드를 쓰세요.
문자 입력은 접근성 입력을 지원하는 입력 칸에서 가능합니다.
잠금 화면·화면 회전·최대 실행 시간 도달 시 중단합니다.
이미 전달된 긴 제스처는 정지 후 잠깐 마무리될 수 있습니다.
화면·문자·매크로는 기기 안에서 처리하며 앱에 인터넷 권한을 넣지 않았습니다.
앱을 삭제하면 기기 안의 저장 데이터는 사라지므로 JSON으로 백업하세요.
