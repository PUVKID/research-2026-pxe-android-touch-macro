윤석 터치매크로 1.0
갤럭시 노트 10+ · Android 12용 ARM64 APK

설치
1. 이 폴더의 '윤석터치매크로_v1.0_노트10플러스.apk'를 휴대폰으로 옮깁니다.
2. 내 파일 앱에서 APK를 열고, 요청되면 해당 앱의 '출처를 알 수 없는 앱 설치'를 허용합니다.
3. 앱에서 '접근성 켜기'를 누릅니다.
4. 접근성의 설치된 앱/서비스 목록에서 '윤석 터치매크로'를 켭니다.
5. 앱 안의 '인식 테스트 화면'에서 화면 정보와 OCR 터치를 시험합니다.

사용
1. '+ 동작 추가'에서 원하는 동작을 순서대로 넣습니다.
2. '이름으로 저장'을 눌러 저장 목록에 보관합니다. 편집 중 작업도 자동으로 보관됩니다.
3. '컨트롤만 띄우기'를 누른 뒤 자동화할 앱을 열어 원하는 화면으로 이동합니다.
4. 작은 컨트롤의 '시작'을 누릅니다. 기본 시작 대기는 3초입니다.
5. '일시정지/계속' 또는 '정지'로 제어합니다. 실행 중 알림에도 정지 버튼이 있습니다.
6. 컨트롤의 상태 글자를 끌면 위치를 옮깁니다. '편집'으로 앱에 돌아옵니다.
7. 화면을 켠 상태로 같은 화면 방향에서 사용합니다.

가장 중요한 기능: 글자 찾기 → 없으면 뒤로가기 → 다시 확인
1. '글자 찾아 터치'를 추가합니다.
2. 찾을 글자에 예를 들어 '확인'을 입력합니다.
3. 검색 방식은 '자동'을 권장합니다.
4. '글자가 없으면'에서 '뒤로가기 후 다시 찾기'를 선택합니다.
5. 각 화면 검색 시간, 뒤로가기 최대 횟수, 뒤로간 뒤 대기 시간을 정합니다.
예: 화면당 2000ms 확인 → 글자가 없으면 뒤로가기 → 1000ms 대기 → 재검색.
최대 3번 뒤로간 후에도 없으면 정지합니다.
캡처 실패·인식 엔진 오류는 '글자 없음'으로 간주하지 않고 중단합니다.

검색 옵션
- 포함 / 완전 일치 / 정규식
- 공백과 줄바꿈 무시, 영문 대소문자 무시
- 화면 정보만 / OCR만 / 자동(화면 정보 먼저, 못 찾으면 OCR)
- 같은 글자가 여러 개라면 1번째, 2번째 등의 항목 선택
- 정렬 기준: 화면의 위→아래, 같은 높이에서는 왼쪽→오른쪽
- 정규식의 문법은 그대로 유지합니다. 공백 무시는 화면 글자에 적용됩니다.
- '글자 나타날 때까지 대기'와 '글자 조건 분기'도 다른 동작 사이에 추가할 수 있습니다.
- 조건 분기는 글자가 있을 때/없을 때 각각 지정한 동작 번호로 이동합니다. 0은 다음 동작입니다.
- 동작을 재정렬하거나 삭제하면 분기·이동 번호를 다시 확인하세요.

들어 있는 동작 15종
좌표 터치, 두 번 터치, 길게 누르기, 스와이프, 대기,
글자 찾아 터치, 글자 대기, 글자 조건 분기,
뒤로가기, 홈, 최근 앱, 문자 입력, 앱 실행, 동작 번호로 이동, 정지.

편집·실행 기능
- 동작 순서 위/아래 이동, 복제, 사용/사용 안 함, 삭제
- 화면에서 좌표 선택: 해당 위치를 눌러 좌표만 기록합니다. 실제 앱 터치는 하지 않습니다.
- 좌표는 화면 전체의 0~100%입니다. 스와이프는 시작/끝 좌표를 직접 입력합니다.
- 동작마다 반복 횟수와 완료 후 대기 시간
- 전체 반복 횟수(0은 무한), 반복 간격, 시작 전 대기, 최대 실행 시간(0은 제한 없음)
- 이름별 매크로 저장/불러오기/삭제
- JSON 파일 내보내기/불러오기
- 최근 150줄 실행 기록 및 TXT 저장
- 한글 OCR 모델과 나눔고딕 Bold 폰트 내장

제한과 확인
- 지원: Android 11 이상 ARM64. 관리자 기기인 Android 12를 기준으로 제작했습니다.
- 루팅은 필요하지 않습니다.
- OCR은 화면 화질·폰트·배치에 따라 오인식할 수 있으므로 사용할 화면에서 먼저 시험하세요.
- 보안 화면은 화면 캡처를 차단할 수 있습니다. 해당 앱이 글자 정보를 제공하면 '화면 정보만'을 사용하세요.
- 화면이 꺼지거나 잠금 화면이 되거나 방향이 바뀌면 실행이 중단됩니다.
- 시스템 설정의 자동 꺼짐 시간을 직접 조절하세요. 앱은 화면을 강제로 켜지 않습니다.
- 이미 시스템에 전달한 긴 제스처는 정지 후 잠깐 마무리될 수 있습니다.
- 문자 입력은 접근성 입력을 지원하는 입력 칸에서 동작합니다. 먼저 입력 칸을 터치하세요.
- Android 13 이상으로 옮겨 사용할 때 접근성이 차단되면 앱 정보의 '제한된 설정 허용'을 확인합니다.
- 앱은 인터넷 권한 없이 화면과 입력을 기기 안에서 처리합니다.
- 노트 10+ 실물에서의 검증은 기기가 연결되어 있지 않아 수행하지 않았습니다.
검증 상세는 '검증결과.txt'를 확인하세요.
