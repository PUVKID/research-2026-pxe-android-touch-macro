NEX 2차 빌드
Java 17, Android SDK 35, Gradle 8.13, Android Gradle Plugin 8.9.1.
app 소스 패키지는 1차와 동일하며 앱 이름은 NEX, versionCode는 2입니다.

권장 경로
.\2차\source
SDK는 local.properties의 sdk.dir로 지정합니다.
work/signing의 개인 키를 보관해야 1차/2차 위에 업데이트할 수 있습니다.

현재 PC의 경로 별칭
NEXSource2, NEXTools, NEXSigning, NEXReference는 한글 경로를 처리하지 못하는 일부 Android 도구를 위한 연결입니다. 실제 파일은 매크로 폴더 안에 있습니다.
PowerShell에서:
$env:JAVA_HOME='.\work\tools\jdk-17.0.20.1+1'
$env:NEX_SIGNING_DIR='./코드/NEXSigning'
.\work\tools\gradle-8.13\bin\gradle.bat :app:assembleRelease :app:testDebugUnitTest :app:lintDebug

다른 PC
Java 17, SDK 35를 설치하고 local.properties의 SDK 경로를 수정하세요.
개인 서명은 source 기준 ../../work/signing 또는 NEX_SIGNING_DIR 환경 변수로 지정합니다.
키 설정이 없으면 개발용 기본 키로 빌드되므로 기존 설치 앱 위에 업데이트할 수 없습니다.

기기 테스트
gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
두 APK를 테스트용 Android 12 가상 기기에 설치합니다.
adb shell am instrument -w -e disableAnalytics true kr.yunseok.touchmacro.test/androidx.test.runner.AndroidJUnitRunner
테스트는 접근성 서비스를 켜고 화면 제스처를 실행합니다. 사용자 실기기 대신 테스트용 가상 기기를 사용하세요.

release APK는 Note 10+ ARM64용이며 debug APK는 가상 기기용 ABI를 포함합니다.
ChromeOS ABI 검사만 이 ARM64 배포 목적에 맞춰 제외했으며 다른 Android Lint 검사는 실행합니다.
