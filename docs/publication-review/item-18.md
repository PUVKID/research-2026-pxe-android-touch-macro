# 🧹 18차 공개 자료 정리

[프로젝트](../../README.md) · [전체 차수](../REVISION_INDEX.md) · [이번 파일별 변경](공개파일변경.json)

하단 실행 진행창에서 실제 완료 횟수와 현재 회차를 구분하고, 터치로 작은 한 줄 표시와 펼친 표시를 전환하도록 구성했습니다. 펼침 최대280dp와 접힘200×48dp, 시간·실행 상태 문구를 사용하며 하단 창에만 겹치는 자동 터치에서는 위쪽 정지를 유지합니다. 17차의 인식 복구와 짧은 자동 스크롤, 기존 저장·실행 설정을 보존한 변경입니다.

[18차 자료](../../18차/)에는 소스150개와 설치·검증·APK 파일 정보·변경 설명을 합쳐155개를 보관합니다. [17차 → 18차 전체 비교](../revision-audit/18차.md)에서 소스와 폴더 전체의 변경 범위를 구분합니다. [주석·공백 포함 소스 패치](../revision-audit/18차.patch), [폴더 전체 패치](../revision-audit/18차.folder.patch), [모든 파일의 전후 크기·해시](../revision-audit/18차.folder.files.json)를 함께 연결합니다. 이전17차는 덮어쓰지 않습니다.

기존 [검수 파일별 변경 목록](이전검수파일변경-18차추가전.json)은 목차 추가 전의 원문 그대로 보관했습니다. 앱 호환에 필요한 패키지·설정 식별자와 빌드 경로 가드, 공개 출처·법적 고지는 유지합니다. 개인 서명 키·인증값·프로필·대화·실행 원문·운영 기록·캐시와 APK 바이너리는 공개하지 않습니다.

18차의 기기·단위 검사 결과와 지원 범위는 [기존 검증 기록](../../18차/검증_결과.md)에 보존했습니다. 이번 문서 연결에서 앱·기기 검사를 다시 실행하지 않았으며 사용자 블루스택·실제 게임·실제 휴대전화·24시간 운용이나 처리 속도 향상·완전 무오류를 뜻하지 않습니다. 이번 앱 수정에 대응하는 학술 원고는 없습니다.
