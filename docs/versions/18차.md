# PXE 18차 · 1.8.0

하단 실행 상태창의 정보와 크기를 줄이고 터치로 접고 펼칠 수 있게 했습니다. 반복 설정의 완료 횟수와 현재 실행 중인 회차를 구분합니다.

## 완료 횟수와 현재 작업

실제 반복이 끝난 뒤에만 완료 수를 올립니다. 예를 들어 15회 설정에서 7회가 끝나고 다음 회차가 실행 중이면 완료7/15와8회째 실행 중을 구분해 표시합니다. 목록에 들어가서 실행하는 반복 수와 목록 전체를 돌아온 바퀴 수를 혼용하지 않습니다. 예시 숫자는 실행 화면에 고정하지 않습니다.

현재 단계는 짧은 문구로, 실행·대기·일시정지·완료·중단 상태는 색 이외의 글자로도 확인할 수 있습니다. 시간과 완료 바퀴 수는 펼친 창에서 계속 확인하고 기존 실행 기록의 상세 문구를 유지합니다.

## 작은 상태창과 터치

펼친 상태창의 최대 폭을280dp로 줄이고 터치하면200×48dp의 한 줄 표시로 접습니다. 다시 터치하면 펼칩니다. 화면이 좁으면 사용 가능한 너비에 맞추고 기존 나눔고딕 Bold와 라이트·다크 테마를 유지합니다.

자동 제스처가 하단 진행창에만 겹치면 진행창만 숨겨 상단 정지 버튼을 유지합니다. 모든 제스처 경로를 먼저 확인하며, 상단 제어창에도 겹치는 경우는 기존 전체 숨김 보호를 우선합니다. 터치가 끝나면 캡처·녹화·기존 표시 조건을 다시 적용해 복원합니다. 표시를 접는 동작이 매크로를 다시 시작하거나 반복 수를 바꾸지는 않습니다.

## 기존 기능과 보존

17차의 인식 복구와 짧은 자동 스크롤, 글자·영역·우선순위·중복 방지·반복·시간 설정을 유지합니다. 같은 앱 ID와 서명의 APK로 기존 앱을 삭제하지 않고 업데이트할 수 있습니다. 이전17차는 그대로 보존합니다.

## 실제 검사와 한계

별도 검증자가 최종 소스와 APK로 기기114개와 단위104개를 직접 통과했습니다. 단위 검사는19클래스·실패/오류/생략0이며 린트 문제는0개입니다.

| 독립 기기 검사 | 통과 수 | 실제 소요 | 제한 |
|---|---:|---:|---:|
| required | 52 | 330.484초 | 720초 |
| recognition | 12 | 37.469초 | 240초 |
| adaptive | 25 | 94.250초 | 480초 |
| recovery | 15 | 56.172초 | 240초 |
| hud | 10 | 54.328초 | 240초 |

실제15회 완료 횟수와 현재 회차 구분, 터치 접기·복원, 일시정지·정지, 자동 터치와 녹화 입력, 라이트/다크·작은 화면·글꼴 확대를 확인했습니다. 기존 인식·반복·업데이트 회귀를 포함하며 이전17차146항목을 보존했습니다.

사용자 블루스택·게임·실제 노트10+·24시간 운용은 검사하지 않았습니다. 이번 표시 개선으로15회 처리 속도나99% 정확도·완전 무오류를 주장하지 않습니다.


## 공개 범위

앱·검사·빌드 소스와 글꼴/OFL, 사용법과 변경 설명을 보관합니다. 개인 프로필·대화·서명 키·인증값·실행 원문·로컬 운영 기록·캐시는 공개하지 않습니다. APK는 로컬로 제공하고 공개 문서에는 파일명·크기·SHA-256을 기록합니다. 이번 앱 수정에는 학술 원고가 없습니다.
