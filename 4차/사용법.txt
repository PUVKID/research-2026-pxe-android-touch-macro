NEX · 4차 / 4.0
갤럭시 노트 10+ · Android 12용 ARM64 APK

설치
NEX_4차_v4.0_노트10플러스.apk를 휴대폰으로 옮겨 기존 NEX 위에 업데이트 설치하세요.
기존 앱을 지우지 않아야 저장한 매크로가 유지됩니다.
처음 설치한다면 앱 오른쪽 위 '연결하기'에서 접근성 → NEX를 켭니다.

새 기능: 글자 탐지 → 매크로 → 뒤로가기 → 반복
1. '매크로' 탭에서 실행할 동작들을 만들고 이름으로 저장합니다.
2. '탐지' 탭 → '탐지 설정'을 엽니다.
3. 찾을 글자와 실행할 매크로를 고릅니다.
   '현재 매크로'를 선택하면 현재 편집본을 사용합니다.
4. 새로고침 간격을 지정합니다. 기본은 60초입니다.
   '화면을 아래로 당기기': 손가락을 화면 30% 높이에서 75% 높이로 내립니다.
   '목록 아래로 이동하기': 손가락을 화면 75% 높이에서 30% 높이로 올립니다.
   실제 새로고침 여부는 대상 앱이 이 동작을 지원하는지에 따라 달라집니다.
5. 탐지할 앱을 열어 원하는 화면을 준비합니다.
6. 화면 위 NEX 아이콘을 펼치고 ⋮ → '화면에서 탐지 영역 지정'을 누릅니다.
7. 원하는 글자가 나올 부분을 사각형으로 그린 뒤 '이 영역 사용'을 누릅니다.
   이 과정의 터치는 대상 앱으로 전달되지 않습니다.
8. 컨트롤의 ⋮ → '글자 탐지 시작'을 누릅니다.

반복 순서
- 시작 3초 뒤 지정한 영역에서 글자를 찾습니다.
- 글자가 없으면 2초 대기 후 다시 확인하고, 기본 60초마다 새로고침 제스처를 실행합니다. OCR 처리 시간이 추가될 수 있습니다.
- 발견하면 선택한 매크로를 실행합니다.
- 매크로가 정상 완료되면 기본 1회 뒤로가고, 바로 다시 탐지합니다.
- 다음 새로고침까지 기다리려면 탐지 설정의 완료 후 다음 새로고침까지 대기를 켜세요.
  이 옵션을 켜면 같은 글자가 남아 있을 때 바로 연속 실행되는 것을 막을 수 있습니다.
- 매크로 실행 중에는 별도의 새로고침이 끼어들지 않습니다.
- 매크로 실행 오류나 사용자의 정지가 발생하면 자동 뒤로가기와 반복도 중단됩니다.

탐지 세부 설정
'탐지 설정 → 세부 설정 보기'에서 지정합니다.
- 자동 인식 / 화면 정보 / 한글 OCR
- 포함 / 완전 일치 / 정규식 비교
- 탐지 영역의 왼쪽·위·오른쪽·아래 비율
- 뒤로가기 횟수
- 새로고침 후 대기, 뒤로가기 후 대기
- 전체 탐지 제한 시간
- 매크로 전에 찾은 글자를 먼저 터치할지 여부 (기본 꺼짐)

글자는 인식된 글자 영역의 중심이 지정 영역 안에 있을 때만 일치로 봅니다.
기본 동작은 '글자를 발견하면 매크로 시작'입니다. 글자 자체를 먼저 누르려면 해당 옵션을 켜세요.
탐지에 쓰는 매크로의 전체 반복은 1회 이상으로 지정해야 합니다. 무한 반복은 사용할 수 없습니다.
매크로 실행 제한이 0분이면 탐지 모드에서는 매크로 한 번 실행을 최대 30분으로 제한합니다.
설정을 바꾼 뒤에는 정지하고 다시 시작해야 새 설정이 적용됩니다.
뒤로가기 한 번으로 원래 화면에 돌아가지 않는 앱은 뒤로가기 횟수와 대기를 조절하세요.

더 작아진 컨트롤
- 처음에는 NEX 앱 아이콘만 표시됩니다.
- 아이콘을 누르면 작은 한 줄 컨트롤이 펼쳐집니다.
- 펼친 상태에서도 왼쪽 NEX 아이콘을 누르면 즉시 접힙니다.
- 아이콘을 끌어 위치를 옮깁니다.
- 아이콘을 길게 누르면 실행을 정지합니다.
- ▶ 시작/계속, Ⅱ 일시정지, ■ 정지, ⋮ 메뉴
- 실행 상태와 시간은 ⋮ → '실행 상태'에서 확인합니다.
- 접힌 상태와 탐지 중에는 터치 번호 점을 숨겨 화면을 덜 가립니다.
- 알림의 정지와 컨트롤 닫기 버튼도 사용할 수 있습니다.
- 편집 화면으로 들어오면 실행 중 작업이 일시정지합니다. 화면 아래 '실행 정지'로 끝낼 수 있습니다.

앱 아이콘
홈 화면, 최근 앱, 앱 내부, 접힌/펼친 컨트롤, 알림에 NEX 아이콘을 적용했습니다.
안드로이드 알림 상단에는 시스템 형식에 맞춘 단색 N 아이콘이 표시됩니다.
라이트·다크와 나눔고딕 Bold 글꼴을 유지했습니다.

기존 기능
글자 탭의 '글자 찾기 시작'은 한 번 찾고 터치하는 기능입니다.
없으면 뒤로가기 후 최대 3회 다시 찾을 수 있습니다.
'미리보기'는 인식 위치만 초록 테두리로 표시합니다.
글자 동작은 매크로의 다른 동작 사이에도 넣을 수 있습니다.
탭, 더블 탭, 길게 누르기, 스와이프, 곡선, 확대·축소, 동시 터치,
녹화 제스처, 대기, 뒤로/홈/최근 앱/알림, 문자 입력, 앱 실행, 조건 분기 등을 제공합니다.
매크로 탭의 더보기에서 실행 설정, 저장본, JSON 가져오기/내보내기를 관리합니다.
컨트롤의 ⋮ → '동작 / 녹화'에서 녹화·동작 목록·저장·편집·점 표시를 사용합니다.

한글 OCR은 기기 안에서 처리됩니다. APK에 OCR 모델과 글꼴을 포함했습니다.
화면이 잠기거나 방향이 바뀌면 실행이 중단됩니다.
보안 화면은 캡처가 제한될 수 있으며, OCR 정확도는 글꼴과 화질에 따라 달라집니다.
처음에는 '현재 화면 인식 미리보기'로 영역과 인식 결과를 확인하세요.
