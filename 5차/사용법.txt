NEX 5차 — 관리자 반복 탐지 모드

원하는 동작
글자 발견 → 그 글자를 눌러 들어가기 → 선택한 매크로 15회 → 뒤로가기 → 10초 대기 → 스크롤 새로고침 → 다시 탐지

처음 설정
1. 기존 NEX 위에 이 APK를 설치합니다. 앱을 삭제하지 않아야 저장한 매크로가 유지됩니다.
2. 접근성을 연결합니다.
3. 매크로 탭에서 들어간 화면 안에서 할 동작을 만들고 ‘이름으로 저장’합니다.
4. 탐지 탭 → ‘글자 · 매크로 설정’에서 찾을 글자와 매크로를 고릅니다.
5. ‘들어간 뒤 매크로 반복’은 15, ‘새로고침 간격’은 10으로 둡니다.
6. ‘찾은 글자를 눌러 들어가기’를 켭니다. 기본으로 켜져 있습니다.
7. 대상 앱의 목록 화면에서 컨트롤 더보기 → ‘화면에서 탐지 영역 지정’을 선택합니다.
   글자가 나타날 부분을 손가락으로 사각형으로 그리고 ‘이 영역 사용’을 누릅니다.
8. 컨트롤 더보기 → ‘글자 탐지 시작’을 누릅니다. 3초 뒤 첫 탐지를 시작합니다.

반복 방식
- 지정 영역에서 글자를 찾으면 그 글자의 가운데를 한 번 눌러 들어갑니다.
- 들어간 화면이 준비될 시간을 기다린 뒤 매크로를 첫 동작부터 15회 실행합니다.
- 저장한 매크로의 전체 반복이 15여도 15×15=225회로 실행하지 않습니다. 탐지 설정의 15회를 사용합니다.
- 각 동작 자체의 개별 반복은 그대로 적용됩니다. 한 회의 동작을 매크로에 기록해 주세요.
- 매크로가 정상적으로 끝나면 앱이 뒤로가기를 누릅니다. 이 자동 뒤로가기를 매크로 끝에 중복으로 넣지 마세요.
- 뒤로가기 후 화면 대기 뒤부터 10초를 세고, 아래로 당겨 새로고침한 다음 다시 탐지합니다.
- 글자가 없으면 매크로를 실행하지 않고 10초마다 새로고침하며 계속 찾습니다.
- 매크로 실행 도중에는 새로고침을 끼워 넣지 않습니다.
- 매크로 오류가 나면 전체 탐지를 중단합니다.

시간은 모두 초로 입력
1 = 1초 / 0.5 = 반 초 / 1.5 = 1.5초 / 10 = 10초
시간 입력과 동작 목록에 초를 표시합니다. 새로고침 간격은 정수 초입니다.
기존 매크로의 시간은 그대로 유지되며 표시와 입력 단위만 바뀝니다.
파일 백업용 JSON은 기존 저장본 호환을 위해 원래 내부 시간 형식을 유지합니다.

화면이 느리게 열릴 때
‘글자 · 매크로 설정’ → ‘세부 설정 보기’에서 ‘들어간 뒤 화면 대기’를 늘립니다.
들어간 뒤 / 새로고침 후 / 뒤로가기 후 화면 대기는 기본 1.5초입니다.
저장한 매크로의 시작 전 대기도 추가로 적용됩니다.
실제 새로고침 시점은 화면 응답과 OCR 처리 시간에 따라 설정 시점보다 늦어질 수 있습니다.

다른 방식도 가능
세부 설정에서 ‘완료 후 새로고침부터 다시 시작’을 끄면 뒤로간 뒤 바로 다시 탐지합니다.
새로고침 방향, 뒤로가기 횟수, 인식 방식, 비교 방식, 영역 좌표도 조절할 수 있습니다.
4차에서 업데이트하면 기존 글자·영역·매크로 선택은 유지하고, 새 기본 흐름(15회·10초·글자 터치·새로고침 대기)을 적용합니다.
