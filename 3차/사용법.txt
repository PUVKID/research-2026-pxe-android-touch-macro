NEX (넥스) · 3차 / 3.0
갤럭시 노트 10+ · Android 12 기준 · ARM64 APK

저장 위치
.\3차
1차와 2차는 보존했습니다. 이후 새 릴리즈는 4차, 5차 순서로 새 폴더에 저장합니다.

설치
NEX_3차_v3.0_노트10플러스.apk를 휴대폰으로 옮겨 설치하세요.
1차·2차와 같은 앱 ID와 서명 키이므로 업데이트 설치할 수 있습니다.
기존 앱을 삭제하지 않고 업데이트하면 저장한 매크로를 유지할 수 있습니다.
처음 설치한 뒤 오른쪽 위 '연결하기'에서 접근성 설정을 열고 NEX를 켭니다.

가장 간단한 사용법
1. 글자 탭에서 찾을 문구를 입력합니다.
2. 없으면 뒤로가기 후 다시 찾을지 선택합니다. 재검색은 최대 3회입니다.
3. '글자 찾기 시작'을 누르면 3초 뒤 인식해 해당 위치를 터치합니다.
4. '미리보기'는 초록 테두리로 인식 위치만 표시합니다.
5. '인식 설정'에서 자동 / 화면 정보 / 한글 OCR, 포함 / 완전 일치 / 정규식을 선택합니다.
6. '매크로에 이 글자 추가'로 다른 터치나 스와이프 사이에 글자 인식을 넣을 수 있습니다.

다른 앱에서 사용
1. 아래 '다른 앱에서 사용'을 눌러 컨트롤을 띄웁니다.
2. 원하는 앱으로 이동합니다.
3. 컨트롤의 '글자'에서 문구를 입력해 실행하거나 미리보기를 확인합니다.
4. 현재 매크로는 '시작', '일시정지', '계속', '정지'로 제어합니다.
5. 위쪽 상태 문구를 끌어 컨트롤을 이동합니다.
6. 더보기(⋮)에 동작 추가, 녹화, 동작 목록, 저장, 편집, 점 표시, 설정, 접기, 닫기가 있습니다.
7. 작은 NEX 버튼을 누르면 펼쳐지고, 길게 누르면 정지합니다.
8. 알림의 정지 버튼도 사용할 수 있습니다.

매크로 만들기
매크로 탭에는 동작 추가와 녹화가 있습니다.
동작 제목이나 설명을 누르면 편집할 수 있습니다.
동작 옆 ⋮에서 순서 이동, 복제, 사용 여부, 삭제를 선택합니다.
매크로의 더보기에는 실행 설정, 좌표 선택, 이름 저장, 저장한 매크로,
새 매크로, JSON 내보내기/불러오기, 정지가 있습니다.
전체 반복, 시작 위치, 시작 대기, 최대 실행 시간은 실행 설정에서 지정합니다.
글자 동작의 검색 영역, 위치 보정, 비교 방식, 재검색 횟수,
같은 글자 중 순번 등은 편집창의 '세부 설정 보기'에서 지정합니다.

녹화
컨트롤 더보기의 '녹화'를 누르고 화면에 탭·곡선·두 손가락 제스처를 그립니다.
손을 떼면 원래 앱에 그 제스처를 재생한 뒤 다음 동작을 녹화합니다.
'완료'로 녹화를 끝냅니다. 취소해도 이미 완료한 동작은 현재 매크로에 남습니다.
제스처 사이 대기도 저장됩니다. 동시 경로 최대 20개, 한 동작 최대 59초입니다.

화면 설정
설정 → 화면 모드: 기기 설정 / 라이트 / 다크
설정 → 화면 위 컨트롤: 크기 / 투명도 / 번호 표시 / 실행 중 화면 켜짐 유지
나눔고딕 Bold 글꼴과 한글 OCR 모델을 앱에 포함했습니다.
화면과 입력은 기기 안에서 처리됩니다. 앱에 인터넷 권한이 없습니다.

확인 사항
글자 인식은 폰트·화질·화면 구조에 따라 달라질 수 있으니 미리보기로 먼저 확인하세요.
보안 화면은 캡처가 제한될 수 있습니다. 문자 입력은 접근성 입력을 지원하는 칸에서 가능합니다.
잠금 화면, 화면 회전, 최대 실행 시간 도달 시 중단됩니다.
이미 전달한 긴 제스처는 정지 후 잠깐 마무리될 수 있습니다.
앱 삭제 시 앱 안의 저장본도 삭제되므로 JSON 파일로 백업하세요.

검증
Android 12 가상 기기에서 글자 인식, 한글 OCR, 뒤로가기 재검색,
터치·스와이프·멀티터치, 녹화/재생, 일시정지/정지 동작을 확인했습니다.
27개 단위 검사 및 2개 기기 통합 검사 통과, 정적 검사 문제 없음.
실제 관리자의 노트 10+ 기기는 연결되어 있지 않아 실기기 검증은 하지 못했습니다.
