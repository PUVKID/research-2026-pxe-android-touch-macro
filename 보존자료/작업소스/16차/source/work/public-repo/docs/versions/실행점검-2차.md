# 실행점검/2차 · BlueStacks 화면 캡처의 별도 점검 도구

[프로젝트 소개](../../README.md) · [전체 차수 비교](../VERSIONS.md) · [원본 보관 폴더](../../../../../../../../%EC%8B%A4%ED%96%89%EC%A0%90%EA%B2%80/2%EC%B0%A8)

**자료 상태: 별도 실행점검 자료**

## 🎯 개발 내용

BlueStacks 화면 캡처의 별도 점검 도구를 정리했습니다.

## ✨ 구현과 변경 내용

capture_readonly.py는 고정된 로컬 BlueStacks ADB 대상에서 연결·PNG 캡처를 수행하고 CRC·크기·해시·명령 JSONL을 기록합니다. 제품 앱의 2차 소스나 새 UI 구현이 아닙니다.

근거: [run (1~137행)](../../../../../../../../%EC%8B%A4%ED%96%89%EC%A0%90%EA%B2%80/2%EC%B0%A8/capture_readonly.py#L1-L137)

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 기존 로컬 BlueStacks ADB 대상 |
| 처리 | setup 연결 또는 capture 화면 읽기와 PNG 검사 |
| 출력 | PNG 화면·CRC/크기/해시·명령 JSONL |

## 🔎 이전 보관본과 비교

제품 차수와 비교하지 않는 독립 점검 자료입니다. 앱 소스와 스크린샷 수집 도구를 하나의 버전 진행으로 합치지 않습니다.

## 🚀 실행 경로와 제약

capture_readonly.py의 setup/capture 분기는 원래 고정된 로컬 장치·도구 경로를 전제로 합니다. 실행점검을 위한 화면 캡처 도구입니다. 새 캡처에는 화면의 개인 데이터가 담길 수 있습니다.

코드/의 차수 밖 NEX 자료와 실행점검/2차는 별도로 안내합니다. 실행점검/2차는 제품 앱의 2차가 아닙니다. 

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../../../../../../../../docs/SANITIZATION.md)를 함께 확인해 주세요.
