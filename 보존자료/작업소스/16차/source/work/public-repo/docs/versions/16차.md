# PXE 16차 · 1.6.0

기존 매크로를 유지하면서 연속 글자 조건을 기다리는 시간을 줄이고 실행 시간을 확인할 수 있게 했습니다.

## 동작 변화

매크로 편집의 **다음 글자에 맞춰 진행**은 기본 꺼짐입니다. 켜면 같은 인식 방식·영역의 인접 글자 조건에서 다음 글자의 사전 부재가 확인된 경우, 완료 후 대기를 다음 조건의 대기로 이전합니다. 다음 글자가 새로 보이면 즉시 다음 단계를 진행합니다. 수동 대기·반복 간격·무작위 대기·이미 보이는 조건은 기존 의미를 유지합니다. 기존 프로필의 숫자를 일괄 변경하지 않습니다.

바로 다음 개별 글자 터치가 같은 위치이면 사라졌다 다시 나타나는 것을 확인합니다. 전체 반복 경계와 개별 동작 반복의 모든 중복을 차단하는 설정은 아닙니다. 목록 탐지의 기존 중복 방지 설정은 따로 유지합니다.

개별 글자 터치의 준비 뒤 대상을 확인하고 전달 직전 관측된 창·일시정지 세대를 대조합니다. 즉시 일시정지·정지한 실행을 대기열 작업이 다시 초기화하는 경합도 수리했습니다. Android 창 전환과 제스처 전달의 원자성을 보증하지 않습니다.

## 화면과 측정

홈 모델은 실제 OBJ224정점·168면을 원근 투영하고 면 조명을 계산합니다. 상시 애니메이션 루프 없이 상태 변화에 맞춰 갱신합니다. 나눔고딕 Bold·라이트/다크·48dp 조작 영역을 유지합니다.

단계·OCR·캡처·설정 대기의 실제 시간을 하단 상태에 표시합니다. 단계 시간은 하위 작업을 포함하므로 항목을 모두 더한 값은 전체 시간이 아닙니다.

## 검사와 성능 기록

별도 검증자가 기본 기능52개·추가 인식/설정12개·새 대기/제어/입체 화면25개, 총89개를 소유 Android31 기기에서 직접 통과했습니다. 작은 화면10개를 포함합니다. Gradle 단위98개는 실패·오류·누락0이고 린트 문제0입니다. 업데이트 설정 보존, 정지·일시정지·다른 앱으로의 전환, 실제 OCR 재확인·영역·재등장 조건을 포함합니다.

CPU4·RAM2048MiB·540×1140/210dpi·swiftshader의 같은 화면에서 **글자 터치2단계×15회**를 비교했습니다. 15차는94.336초,16차는67.087초였고 별도 검증자가16차67.518초를 재확인했습니다. 각각 실제 OCR60회·30터치·오터치0, InputImage540×1140·글자배율1.0·최소 ink26×28을 확인했습니다. 새설치 후 추가 워밍업은 없었습니다. 첫 비교 한 쌍의27.249초 차이는 이 조건의 관측이며 제품의 보편적 개선률이 아닙니다.

CPU2의 같은 저해상도 시험은 기한 안에 완주하지 못했습니다. 재부팅 뒤 전체 회귀 검사 후 별도로 측정해도125.075초에7회로 미달했습니다. 이 실패는 CPU4 성공과 별도로 보존하고 120초 기준을 늘리지 않았습니다. 사용자 블루스택 설정을 자동 변경한 결과도 아닙니다.

기본1080×2280/420dpi의 초기 성능 시험은 두 버전 모두 제한 안에15회를 완주하지 못했습니다. 이 실패는 저해상도 별도 실험으로 대체하지 않습니다. 제품에는 OCR 생략·축소·새 이미지 캐시를 추가하지 않았습니다.

합성 화면의 일치 판정100개는100개의 독립 게임 화면이 아닙니다. 실제 게임99%·사용자 블루스택5개·노트10+ 실기기·24시간 무중단은 이번 소유 시험 기기 결과로 보증하지 않습니다.
