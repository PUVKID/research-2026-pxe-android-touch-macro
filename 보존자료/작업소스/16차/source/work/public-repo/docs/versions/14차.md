## 🚀 실행 경로와 제약

MainActivity와 접근성 MacroService가 앱 진입·실행을 나눕니다. 원래 Gradle 프로젝트의 manifest·리소스·wrapper JAR·SDK·서명 입력을 함께 준비해야 하며 공개 코드만으로 설치 APK가 만들어진다고 보장하지 않습니다. 실제 기기 접근성 설정은 사용자가 직접 허용해야 합니다. 

코드/의 차수 밖 NEX 자료와 실행점검/2차는 별도로 안내합니다. 실행점검/2차는 제품 앱의 2차가 아닙니다. 

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../../../../../../../../docs/SANITIZATION.md)를 함께 확인해 주세요.
