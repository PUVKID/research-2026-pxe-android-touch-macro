## 🎯 이 자료의 목적

이 문서는 차수 밖 NEX 소스·개발 도구 묶음에 관한 안내입니다. 아래 설명은 보관된 소스의 동작과 차이를 정리했으며 새 실행 결과를 뜻하지 않습니다.

## ✨ 구현과 변경 내용

코드/NEXSource2는 MainActivity·MacroService·FloatingController와 제스처 처리 소스를 보관합니다. NEXSource3에는 wrapper 등 일부 파일만 있으며 이름만으로 제품 2차·3차 전체 배포본이라 판단하지 않습니다.

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 저장된 동작·텍스트 조건·좌표·영역과 사용자 접근성 권한 |
| 처리 | MainActivity 편집 → Store 저장 → MacroService 실행 → 캡처·인식·제스처 |

## 🔎 이전 보관본과 비교

비교할 숫자 차수 이력이 없어 현재 구성의 역할을 설명합니다. 폴더명이나 파일 수만으로 이전 릴리스 대비 새 기능이라고 부르지 않습니다.

## 🚀 실행 경로와 제약

MainActivity와 접근성 MacroService가 앱 진입·실행을 나눕니다. 원래 Gradle 프로젝트의 manifest·리소스·wrapper JAR·SDK·서명 입력을 함께 준비해야 하며 공개 코드만으로 설치 APK가 만들어진다고 보장하지 않습니다. 실제 기기 접근성 설정은 사용자가 직접 허용해야 합니다. 이번 문서 작업에서는 Gradle 빌드·기기 제스처·OCR을 실행하지 않았습니다.

코드/의 차수 밖 NEX 자료와 실행점검/2차는 별도로 안내합니다. 실행점검/2차는 제품 앱의 2차가 아닙니다. 현재 공개 목록에 없는 제품 2차·7차의 변화는 추정하지 않았습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../../../../../../../../docs/SANITIZATION.md)를 함께 확인해 주세요.
