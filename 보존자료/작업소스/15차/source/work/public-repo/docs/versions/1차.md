# 1차 · 동작 편집·접근성 서비스의 초기 구조

[프로젝트 소개](../../README.md) · [전체 차수 비교](../VERSIONS.md) · [원본 보관 폴더](../../../../../../../../1%EC%B0%A8)

**자료 상태: 이전 보관본**

## 🎯 이 자료의 목적

이 문서는 동작 편집·접근성 서비스의 초기 구조에 관한 안내입니다. 아래 설명은 보관된 소스의 동작과 차이를 정리했으며 새 실행 결과를 뜻하지 않습니다.

## ✨ 구현과 변경 내용

MainActivity에서 동작을 편집하고 MacroService가 접근성 제스처와 글자 조건을 실행합니다. Store의 JSON 저장과 Step 검증, 서비스 내 초기 패널 구조를 확인할 수 있습니다.

근거: [MainActivity (1~172행)](../../../../../../../../1%EC%B0%A8/source/app/src/main/java/kr/yunseok/touchmacro/MainActivity.java#L1-L172) · [MacroService (1~231행)](../../../../../../../../1%EC%B0%A8/source/app/src/main/java/kr/yunseok/touchmacro/MacroService.java#L1-L231) · [Step (1~46행)](../../../../../../../../1%EC%B0%A8/source/app/src/main/java/kr/yunseok/touchmacro/Step.java#L1-L46) · [Store (1~16행)](../../../../../../../../1%EC%B0%A8/source/app/src/main/java/kr/yunseok/touchmacro/Store.java#L1-L16)

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 저장된 동작·텍스트 조건·좌표·영역과 사용자 접근성 권한 |
| 처리 | MainActivity 편집 → Store 저장 → MacroService 실행 → 캡처·인식·제스처 |
| 출력 | 매크로 JSON·진행 상태·동작/인식/오류 기록 |

## 🔎 이전 보관본과 비교

현재 공개 목록에서 이 프로젝트의 첫 숫자 차수입니다. 그 이전 구현의 기능·상태는 이 자료만으로 확정하지 않습니다.

## 🚀 실행 경로와 제약

MainActivity와 접근성 MacroService가 앱 진입·실행을 나눕니다. 원래 Gradle 프로젝트의 manifest·리소스·wrapper JAR·SDK·서명 입력을 함께 준비해야 하며 공개 코드만으로 설치 APK가 만들어진다고 보장하지 않습니다. 실제 기기 접근성 설정은 사용자가 직접 허용해야 합니다. 이번 문서 작업에서는 Gradle 빌드·기기 제스처·OCR을 실행하지 않았습니다.

코드/의 차수 밖 NEX 자료와 실행점검/2차는 별도로 안내합니다. 실행점검/2차는 제품 앱의 2차가 아닙니다. 현재 공개 목록에 없는 제품 2차·7차의 변화는 추정하지 않았습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../../../../../../../../docs/SANITIZATION.md)를 함께 확인해 주세요.
