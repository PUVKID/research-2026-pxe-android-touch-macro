## 수정한 동작

목록 탐지와 매크로의 개별 글자 동작은 인식 방식이 각각 저장됩니다. 기본 설정에서 방식을 바로 선택하고 적용 범위를 읽을 수 있도록 바꿨습니다. 화면 정보 방식에서는 OCR을 호출하지 않으며 오류 안내는 실제 실행 단계와 요청·실제 인식 방식을 구분합니다.

캡처 기본 보호 간격은 Android API31 이상 0.5초, API30 1.1초입니다. 간격 거절 때 최대 12초까지 늘리고 성공하면 절반씩 기본값으로 회복합니다. 활성 탐지의 반복 대기도 줄였습니다. 실제 OCR 처리 시간이나 사용자가 저장한 대기까지 0초로 만드는 설정은 아닙니다.

목록 설정의 세부 설정에서 인식 즉시 들어가기를 선택할 수 있습니다. 기본은 꺼짐이며 켜면 터치 전 재확인을 생략합니다. 개별 글자 동작의 계속 기다리기와 즉시 진행도 유지합니다. 빠르게 바뀌는 화면에서는 재확인을 유지하는 편이 정확합니다. 기존 저장 대기값은 자동으로 줄이지 않았습니다.

기본 설정은 글자·방식·매크로·반복·새로고침·완료 후 대기에 집중하고 나머지 대기와 세부 설정은 펼쳐 편집합니다. 기존 5단계 안내, 최대 6순위, 반복·중복 제어, 정지·일시정지, 로그와 라이트·다크 모드를 유지합니다. 나눔고딕 Bold와 라이선스도 포함합니다.

영역 경계의 글자 소실을 피하기 위해 전체 화면 OCR 후 기존 중심점 필터·같은 글자 순번·순위 캐시를 유지합니다. 대상 앱의 접근성 정보 제공 여부와 OS의 화면 캡처 제한은 그대로 적용됩니다.

기기 검사는 별도로 소유한 Android 12/API31 에뮬레이터에서 수행했습니다. 글자 탐지·대기·재확인·정지·일시정지·캡처 응답·영역·순위 캐시·대상 앱 경계·업데이트 보존·저장/취소·작은 화면의 안내 흐름을 포함합니다. 최신 기본 설정 화면도 직접 확인했습니다.

검사 중 개인 기억 참조 지침이 갱신되어 마지막 동결 확인이 차단됐습니다. 제품 소스 120개와 APK는 불변이었고, 새 지침을 독립 검토해 제품 요구 변경이 없음을 확인한 뒤 새 전역 지침에 최종 판정을 연결했습니다. 앞선 52개를 새 지침 아래 다시 실행했다고 소급하지 않았습니다.

구 캡처 간격 4/8/8초 검사의 실패는 새 시간 정책에 맞춰 명시적으로 개정한 뒤 전체 재검증했습니다. 이후 독립 Gradle의 한글 실행 경로·명령 호출 오류도 보존하고 기존 지원 빌드 경로로 보정해 재실행했습니다. 최종 누적은 수리13/입력보정7/정식검증실패1이며 과거 실패 영수증은 삭제하지 않았습니다. Git 공백 검사에는 원문 OFL의 2행 공백과 원격 README의 CRLF 경고가 있었으며 제품 린트 결과와 구분했습니다.
