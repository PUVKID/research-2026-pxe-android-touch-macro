# PXE 17차 설치와 변경 사항

블루스택·LD플레이어에는 **PXE_17차_v1.7_PC용.apk**, 노트10+에는 **PXE_17차_v1.7_노트10플러스.apk**를 설치하세요. 기존 앱을 삭제하지 않고 업데이트하면 저장 매크로와 탐지 설정을 유지할 수 있습니다. 설치 뒤 설정 화면에 **1.7.0 · 17차**가 표시되는지 확인하세요.

- 일시적으로 창 정보·화면 정보·OCR 응답이 늦거나 일부 OCR 작업이 취소되면 바로 끝내지 않고, 터치 없이 복구를 기다린 뒤 새 화면으로 다시 인식합니다. 현재 복구 상태는 제어창 상태와 실행 기록에서 확인할 수 있습니다. 정지 버튼은 계속 사용할 수 있습니다.
- 글자가 없을 때 **목록 아래로 스크롤**과 **위로 스크롤 후 다시 찾기**의 손가락 이동 거리를 이전의 절반으로 줄였습니다. 기존 프로필에도 적용되므로 다시 설정할 필요가 없습니다. 직접 녹화·등록한 스와이프와 아래로 당겨 새로고침은 그대로입니다. 실제 목록 이동량은 대상 앱의 관성 처리에 따라 달라질 수 있습니다.
- 화면을 정상적으로 읽었지만 글자가 없을 때의 탐지 제한과 실패 처리, 매크로·탐지의 전체 최대 실행 시간은 기존 설정을 유지합니다. 화면 자체를 읽지 못한 일시 오류는 글자 없음으로 간주하지 않아 뒤로가기나 스크롤 재시도를 실행하지 않습니다.

24시간 사용을 위해 기존 제한 값을 자동으로 바꾸지는 않았습니다. 개별 글자를 계속 기다리려면 해당 동작의 **글자가 나타날 때까지 계속 기다리기**를 사용하세요. 매크로와 탐지의 전체 최대 실행 시간은 각각 별도입니다. 기존 목록 실행에는 저장 매크로에 계속 기다리는 글자 동작이 없으면, 매크로 제한0이어도 한 번 진입한 실행에30분 안전 한도가 적용되는 정책이 남아 있습니다.

보안 캡처 거부·실제 접근성 권한 해제·화면 꺼짐·화면 회전·영구 미응답은 구분합니다. 서비스 연결이 끊겼다면 접근성을 다시 켜야 하며, 이 업데이트가 OS 권한을 우회하지는 않습니다. 오류 기록은 **설정 → 오류 기록**에서 확인할 수 있습니다.

기존16차와 이전 차수는 보존했습니다. 실제 검사 범위와 남은 한계는 검증 결과 문서를 확인하세요.
