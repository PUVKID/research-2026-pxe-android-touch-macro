# PXE 17차 검증 결과

구현자와 별도 검증자가 동일한 최종 소스와 APK로 각각 기기104개(기본52·추가 인식12·적응25·새 복구/스크롤15), 단위100개를 통과했습니다. 단위 검사는18클래스·실패/오류/생략0이고 린트 문제는0개입니다. 독립 기기 검사 시간은 기본335.312초/720초, 추가 인식51.640초/240초, 적응91.969초/480초, 복구55.562초/240초입니다.

소유 Android31 기기(CPU4·RAM2048MiB·1080×2280/420dpi)에서 일시 오류 복구·정지1초 이내·중복 차단·오래된 목록 좌표 미터치·자동 스크롤 두 경로의 절반 이동·수동 스와이프 보존을 확인했습니다. 두 APK의 기존 서명·앱 ID·버전17·ABI·압축과 이전16차140항목 보존도 확인했습니다. 검사 기기에 실제 설치된 PC APK를 다시 읽어 납품 PC APK와 SHA-256이 같음을 확인했습니다.

화면 지연과 오류를 주입한 통제 재현 결과입니다. 사용자 블루스택·실제 게임·노트10+ 실기기·24시간 무중단과 실제 과거 오류 원인은 이번 시험으로 확정하지 않았습니다. 이번 차수의15회 속도 비교는 새로 수행하지 않았습니다.

## 설치

기존 앱을 삭제하지 않고 같은 앱에 업데이트 설치합니다. 블루스택·LD플레이어는 PC용, 노트10+는 노트10플러스용 APK를 사용합니다. 자동 스크롤 두 경로는 기존 저장 프로필에도 적용됩니다.
