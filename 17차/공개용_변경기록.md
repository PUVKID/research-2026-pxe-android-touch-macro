# PXE 17차 · 1.7.0

화면 인식이 잠깐 늦거나 일시 오류가 발생했을 때 실행 전체가 끝나는 경로를 고치고, 글자를 찾지 못한 뒤의 자동 스크롤을 짧게 만들었습니다.

## 인식 복구

대상 창 조회와 명시적으로 선택한 화면 정보 읽기가 늦으면 터치하지 않고 응답을 기다립니다. 한 번에 하나의 조회만 유지하고 응답이 돌아온 뒤 새 화면으로 다시 확인합니다. 자동 인식의 기존 OCR 전환은 유지하며 화면 정보 전용 동작을 임의로 OCR로 바꾸지 않습니다.

완료된 OCR 작업의 일시 사용 불가·시간 만료·취소는 새 화면으로 재시도합니다. 재시도 간격은 0.25초부터 최대 2초이며, 이전 작업의 비트맵 수명과 단일 OCR 작업 제한을 유지합니다. 피드백 알림 중단과 실제 접근성 서비스 연결 해제를 구분하고, 이미 전달한 제스처를 자동으로 다시 실행하지 않습니다.

읽기 실패를 글자 부재로 계산하지 않으므로 오류만으로 뒤로가기·스크롤·중복 잠금 해제가 일어나지 않습니다. 정상적으로 읽은 화면에 글자가 없는 경우의 기존 대기와 실패 정책, 사용자가 지정한 전체 실행 시간, 정지와 일시정지는 유지합니다. 권한·보안 캡처·미지원·잘못된 입력과 확인되지 않은 내부 오류는 구분합니다.

## 자동 스크롤

목록의 아래로 스크롤과 개별 글자 동작의 위로 스크롤 후 다시 찾기는 화면 높이 75%에서 52.5%까지 이동합니다. 기존 75%→30%보다 손가락 이동 거리가 절반이며 기존 저장 프로필에도 적용됩니다. 아래로 당겨 새로고침과 직접 등록·녹화한 스와이프는 유지합니다. 실제 콘텐츠 이동량은 대상 앱의 관성 처리에 따라 달라집니다.

## 실제 검사와 한계

구현자와 별도 검증자가 동일한 최종 소스와 APK로 각각 기기104개(기본52·추가 인식12·적응25·새 복구/스크롤15), 단위100개를 통과했습니다. 단위 검사는18클래스·실패/오류/생략0이고 린트 문제는0개입니다. 독립 기기 검사 시간은 기본335.312초/720초, 추가 인식51.640초/240초, 적응91.969초/480초, 복구55.562초/240초입니다.

소유 Android31 기기(CPU4·RAM2048MiB·1080×2280/420dpi)에서 일시 오류 복구·정지1초 이내·중복 차단·오래된 목록 좌표 미터치·자동 스크롤 두 경로의 절반 이동·수동 스와이프 보존을 확인했습니다. 두 APK의 기존 서명·앱 ID·버전17·ABI·압축과 이전16차140항목 보존도 확인했습니다. 검사 기기에 실제 설치된 PC APK를 다시 읽어 납품 PC APK와 SHA-256이 같음을 확인했습니다.

화면 지연과 오류를 주입한 통제 재현 결과입니다. 사용자 블루스택·실제 게임·노트10+ 실기기·24시간 무중단과 실제 과거 오류 원인은 이번 시험으로 확정하지 않았습니다. 이번 차수의15회 속도 비교는 새로 수행하지 않았습니다.

## 보관과 공개 범위

기존 로컬 16차는 보존했습니다. 같은 앱 ID와 서명의 업데이트 APK를 로컬 17차에 제공하고, 공개 저장소에는 앱·검사·빌드 소스와 글꼴/OFL, 변경 설명을 보관합니다. 서명 키·개인 프로필·실행 원문·캐시는 공개하지 않습니다. 이 앱 수정에 대응하는 학술 원고는 없습니다.

[소스·빌드](source/README.md) · [공백·주석 포함 전체 소스 차이와 해시](https://github.com/PUVKID/PXE-Touch-Macro-Project/blob/main/docs/revision-audit/17%EC%B0%A8.md)

제품 변경과 별도로 기존 공개 관리 문서 36개의 누락 링크 492개를 정비했습니다. 실제 대응 자료 485개로 연결하고, 비공개 로컬 자료 7개는 공개 링크가 없음을 표시했습니다. 로컬의 이전 제품 차수와 앱 동작은 바꾸지 않았습니다.

이번에 갱신한 첫 화면·목차·변경 기록 등 관리 문서는 UTF-8과 LF 개행으로 저장했습니다. 줄바꿈과 링크만 달라진 부분도 저장소 전체 비교에 포함하며 제품 기능 변경과 구분합니다.

공개 폴더의 모든 파일을 다시 세어 첫 화면·전체 차수 목차·비교 목차의 파일 수를 실제 값으로 갱신했습니다. 과거 일부 소스의 집계와 전체 폴더 집계를 구분합니다.
