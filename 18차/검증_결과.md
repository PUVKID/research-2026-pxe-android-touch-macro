# PXE 18차 검증 결과

별도 검증자가 최종 소스와 APK로 기기114개와 단위104개를 직접 통과했습니다. 단위 검사는19클래스·실패/오류/생략0이며 린트 문제는0개입니다.

| 독립 기기 검사 | 통과 수 | 실제 소요 | 제한 |
|---|---:|---:|---:|
| required | 52 | 330.484초 | 720초 |
| recognition | 12 | 37.469초 | 240초 |
| adaptive | 25 | 94.250초 | 480초 |
| recovery | 15 | 56.172초 | 240초 |
| hud | 10 | 54.328초 | 240초 |

실제15회 완료 횟수와 현재 회차 구분, 터치 접기·복원, 일시정지·정지, 자동 터치와 녹화 입력, 라이트/다크·작은 화면·글꼴 확대를 확인했습니다. 기존 인식·반복·업데이트 회귀를 포함하며 이전17차146항목을 보존했습니다.

사용자 블루스택·게임·실제 노트10+·24시간 운용은 검사하지 않았습니다. 이번 표시 개선으로15회 처리 속도나99% 정확도·완전 무오류를 주장하지 않습니다.

소유 Android31 시험 기기(CPU4·RAM2048MiB·1080×2280/420dpi)만 사용했습니다. 같은 앱 ID·버전18/1.8.0·기존 서명·두 APK의 ABI와 압축을 확인했습니다. 실제 설치한 PC APK를 다시 읽어 납품 APK와 SHA-256이 같음을 대조했습니다.

하단에만 겹치는 긴 자동 터치 중에는 위쪽 정지를 유지하고 물리 정지 입력 뒤1초 이내 실행이 멈추며 후속 자동 입력이 없음을 확인했습니다. 상단 제어창에도 겹치는 복수 경로는 기존 충돌 보호를 우선합니다. 원래 상세 기록과 시간 측정, 저장 설정은 유지합니다.

구현 단계의 문구 조합 정적 경고1개는 문자열 리소스 방식으로 수정했습니다. 수정 전 기능114개 통과와 수정 후 집중 검사10개를 구분했고, 별도 검증자는 최종 수정본의114개를 다시 직접 실행했습니다. 이전 실패를 최종 성공으로 덮어쓰지 않았습니다.

매크로를 중단한 다음 기존 앱을 삭제하지 않고 업데이트 설치합니다. 블루스택·LD는 PC용, 노트10+는 노트10플러스용 APK를 사용합니다.
