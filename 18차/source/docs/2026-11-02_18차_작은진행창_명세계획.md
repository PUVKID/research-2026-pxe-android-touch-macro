# 18차 작은 진행창과 실제 반복 횟수

확인일: 2026-11-02. 사용자는 하단 진행창을 더 명확하고 간단하게 만들고, 지정한15회 중 완료 횟수와 현재 회차를 구분하며, 터치로 작게 접어 대상 앱의 시야를 확보하도록 요청했습니다. 기존17차와 모든 매크로 실행 기능을 보존하고18차에만 수정합니다.

## 확인한 원인과 구현 범위

기존RunHud는 최대390dp의 넓은 카드에 상세 진행 문자열과 시간을 그대로 표시하며 FLAG_NOT_TOUCHABLE이라 눌러 접을 수 없습니다. 실제 소유PXE18에서 기존 구현을 설치한 새UI검사1개는 기본 폭996px이280dp보다 크다는 단언에서 실패했습니다. 이는 새 요구의 제어RED이며 사용자 게임의 실제 오류를 재현한 것은 아닙니다.

매크로 전체 반복의 round는 runSequence 내부 변수이며, watchCompleted는 목록 진입·복귀까지 마친 탐지 바퀴 수입니다. 둘을 혼합하면15회 진행을 정확히 표시할 수 없습니다. 새RunProgress는 실제 루프의 총 반복·현재 회차·완료 회차·현재 동작을 한 불변 객체로 전달합니다. 단계 시작과 전체 회차가 실제 끝난 지점에서만 갱신합니다. 시작·정지·새 실행 경합은 기존 generation과 서비스 모니터에서 확인하고 이전 실행의 갱신을 거절합니다. 실행 순서·대기·인식·권한·저장 모델은 바꾸지 않습니다.

## 화면과 조작

- 기본 펼침은 최대280dp로 줄이고 완료7/15회와 현재8회째, 현재 동작을 짧게 나눕니다. 시간은 보조 두 줄에 이번·직전·전체 경과·탐지 바퀴를 보존합니다. 상세 진행 원문과 실행 기록은 그대로 남습니다.
- 진행창을 누르면 최대200dp·높이48dp의 한 줄 표시로 접습니다. 다시 누르면 펼칩니다. 선택은 진행 갱신·일시정지·캡처 숨김/복원·정지·새 실행 및 컨트롤 재생성에서 유지합니다. 자동으로 매번 펼치지 않습니다.
- 라이트/다크의 기존 화이트·민트 팔레트와 나눔고딕Bold를 유지하고 상태를 글자로 구분합니다. 긴 내용은 줄임 표시하며 원문 로그는 자르지 않습니다. 새 장식이나 연속 애니메이션은 넣지 않습니다.
- 클릭 가능한 창은 자체 영역만 터치를 받으며 포커스를 가져가지 않습니다. 자동 제스처가 하단 진행창에만 겹치면 진행창만 숨기고 위쪽 정지를 계속 표시합니다. 모든 경로를 먼저 집계하여 위쪽 제어창에도 겹치는 경우에는 기존 전체 숨김을 우선합니다. 실제finally에서 맞는 종류를 복원하고ticker가숨김을되살리지않습니다. 녹화 시작부터 녹화 재생 종료까지는 진행창을 숨겨 직접 재생 터치를 가로채지 않습니다.

## 검증 계약

기존 필수52/공유720초, 인식12/240초, 적응25/480초, 복구15/240초를 보존합니다. 새hud-check-plan은 기본8/120초,320dp의 테마·긴 문구1/60초, 실제Configuration.fontScale1.3의 테마·접기1/60초로 총10개/공유240초입니다. 기본8개에는 실제하단4000ms누름중위쪽정지의물리터치·1초정지/대상입력취소/후속입력0과첫HUD·뒤제어창다중경로2터치회귀를포함합니다. 글꼴 배율 원문이null이면 삭제로 복원하고 임의1.0으로 대체하지 않습니다.

실제15회 터치와7완료/8회째·일시정지·최종15완료, 탐지 바퀴와 분리된 반복값·다음 진입0부터 시작, 진행창 하단 자동터치와 녹화 재생, 캡처/접기 복원·긴 문구·라이트다크·작은 화면을 검사합니다. 새순수4개와 기존100개, Gradle 단위·lint·엄격UTF-8·17차146개 보존·두APK 앱ID/18/1.8.0/기존서명/ABI/CRC 및17→18 실제 업데이트를 확인합니다.

전용PXE18 Android31/CPU4/RAM2048/1080×2280/420dpi/Swiftshader와 별도ADB5043만 사용합니다. 사용자 블루스택·게임·도커·실폰은 조작하지 않습니다. 사진과 실제 결과를 최종 동결에 연결한 뒤 별도verifier가 독립 검사합니다.24시간 실제 운용·게임 속도 향상·완전 무오류를 이 표시 변경만으로 주장하지 않습니다.
