# PXE 18차 · 1.8.0 설치와 변경사항

기존 PXE를 삭제하지 않고 같은 기기에 맞는 APK를 열어 업데이트합니다. 앱 ID와 기존 서명은 유지합니다. 이전17차 파일과 저장 설정은 보존합니다.

- 블루스택·LD플레이어: `PXE_18차_v1.8_PC용.apk` (ARM64와x86_64)
- 노트10+: `PXE_18차_v1.8_노트10플러스.apk` (ARM64)

## 진행창 사용

실행하면 하단에 **7/15회 완료 · 8회째**처럼 실제 완료 횟수와 현재 실행 중인 회차를 구분합니다. 다음 줄의 **동작 2/4 · 글자 찾아 터치**는 매크로 안의 동작 번호입니다. 개별 동작 반복, 전체15회 반복, 목록 진입부터 복귀까지의 탐지 바퀴는 서로 다른 값입니다.

진행창을 한 번 누르면 최대200dp·높이48dp의 작은 한 줄 표시로 접습니다. 다시 누르면 최대280dp로 펼쳐 현재 단계와 이번·직전 한 바퀴 시간, 전체 경과, 완료 바퀴를 확인합니다. 접기 선택은 실행 중 갱신·캡처·일시정지·정지·다음 실행에도 유지됩니다. 화면 폭이 좁으면 가용 폭에 맞춥니다.

전체15회가 실제 끝난 뒤15/15로 표시합니다. 탐지 매크로는 복귀와 대기 중에도 직전15/15를 유지하고, 다음 항목에 들어갈 때0/15부터 시작합니다. 정지·일시정지 중에는 완료 횟수가 임의로 올라가지 않습니다. 원래 상세 실행 기록과 시간 측정은 유지하며 화면의 긴 문구만 줄임 표시합니다.

진행창에만 겹치는 자동 터치는 하단 표시만 잠깐 숨기고 위쪽 **■ 정지** 버튼을 유지합니다. 여러 터치 경로가 위쪽 제어창 자체에도 겹치는 경우에는 기존 충돌 보호를 우선합니다. 녹화 중에도 진행창을 숨겨 녹화 재생을 가로채지 않습니다. 라이트/다크와 나눔고딕Bold를 유지합니다.

## 유지 범위와 한계

이번 변경은 하단 표시 개선입니다. 기존 인식 복구·짧은 자동 스크롤·우선순위·녹화·15회 반복·뒤로가기·새로고침·중복 방지·접근성 및 대상 앱 보호·최대 실행 시간 설정을 유지합니다. 모든 설정 값을 일괄 변경하지 않습니다.

전용Android12 시험 기기의 자동 회귀와 실제 화면 검사는 사용자 블루스택·게임·실제 노트10+ 또는24시간 연속 운용을 검사한 증거가 아닙니다. 최종 검사 수와 결과는 같은 폴더의 검증 문서를 확인하세요.
